# Information Management and Retrieval

Three pieces of work from the Information Management and Retrieval module of my Computing degree at the University of Plymouth: a REST API, a SQL Server database and a PHP data viewer.

| Project | What it is | Tech |
|---|---|---|
| [Customer Management REST API](customer-api) | An API with GET, POST, PUT and DELETE endpoints for managing customer records through SQL Server stored procedures | C#, ASP.NET Core, Entity Framework Core, SQL Server, Swagger |
| [FarmFord Order Database](order-database) | A normalized database for a farm's customers, produce and orders, with a stored procedure, a view and a trigger | SQL Server, T-SQL |
| [Ancient Trees Data Viewer](ancient-trees-viewer) | A PHP web app that displays Plymouth's open ancient trees dataset as a searchable, sortable table | PHP, JavaScript, jQuery DataTables |

Each folder has its own README with details and setup steps.
